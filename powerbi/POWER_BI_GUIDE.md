# Power BI Integration Guide - Developer Career Intelligence Platform

This document details how to ingest, model, and visualize the exported data mart CSV files in **Microsoft Power BI**.

---

## 1. Data Model & Star Schema Architecture

The platform automatically exports 6 normalized CSV files to `data/processed/powerbi/`:

```
   ┌───────────────────────────┐
   │    developer_metrics      │ (Dimension / Master)
   │  [PK: user_id]            │
   └─────────────┬─────────────┘
                 │ 1:N
     ┌───────────┼───────────────┬────────────────┐
     │           │               │                │
┌────┴─────┐ ┌───┴──────────┐ ┌──┴──────────┐ ┌───┴──────────┐
│repository│ │activity      │ │language     │ │career        │
│_metrics  │ │_metrics      │ │_metrics     │ │_metrics      │
│[FK:user] │ │[FK:user_id]  │ │[FK:user_id] │ │[FK:user_id]  │
└──────────┘ └──────────────┘ └─────────────┘ └──────────────┘
                                      │
                                ┌─────┴──────────┐
                                │peer_benchmark  │
                                │[FK:user_id]    │
                                └────────────────┘
```

### Table Relationships
- `developer_metrics[user_id]` (1) ───< (Many) `repository_metrics[user_id]` (Active, 1-to-many)
- `developer_metrics[user_id]` (1) ───< (Many) `activity_metrics[user_id]` (Active, 1-to-many)
- `developer_metrics[user_id]` (1) ───< (Many) `language_metrics[user_id]` (Active, 1-to-many)
- `developer_metrics[user_id]` (1) ───< (Many) `career_metrics[user_id]` (Active, 1-to-many)
- `developer_metrics[user_id]` (1) ───< (Many) `peer_benchmark[user_id]` (Active, 1-to-many)

## 2. Recommended DAX Measures

Create a dedicated measure table `_Measures` in Power BI with these formulas:

### A. Core Executive Measures
```dax
Total Commits = COUNTROWS(activity_metrics)

Total Repositories = DISTINCTCOUNT(repository_metrics[repo_name])

Total Stars = SUM(repository_metrics[stargazers_count])

Overall Intelligence Score = AVERAGE(developer_metrics[overall_score])

Average Project Complexity = AVERAGE(repository_metrics[complexity_score])
```

### B. Dynamic Ratio & Quality Measures
```dax
Documentation Health % = 
DIVIDE(
    CALCULATE(COUNTROWS(repository_metrics), repository_metrics[has_readme] = TRUE()),
    COUNTROWS(repository_metrics),
    0
) * 100

License Compliance % = 
DIVIDE(
    CALCULATE(COUNTROWS(repository_metrics), repository_metrics[license] <> "None" && NOT(ISBLANK(repository_metrics[license]))),
    COUNTROWS(repository_metrics),
    0
) * 100
```

### C. Top Career Role & Readiness
```dax
Top Career Role = 
CALCULATE(
    SELECTEDVALUE(career_metrics[role_name]),
    FILTER(career_metrics, career_metrics[rank] = 1)
)

Top Career Readiness % = 
CALCULATE(
    MAX(career_metrics[fit_percentage]),
    FILTER(career_metrics, career_metrics[rank] = 1)
)
```

## 3. Recommended Power BI Dashboard Layout (6 Pages)

| Page | Title | Visuals & KPI Cards |
|---|---|---|
| **Page 1** | **Executive Overview** | KPI Cards (`Overall Score`, `Top Role`, `Total Repos`, `Total Stars`), Radar/Spider Visual (`Depth`, `Breadth`, `Consistency`, `Complexity`, `Collaboration`, `Adaptability`), Developer Bio Card |
| **Page 2** | **Technology Analytics** | Treemap (`language_name` by `bytes_count`), Stacked Bar Chart (`Repository` vs `Languages`), Table of Primary vs Supporting Technologies |
| **Page 3** | **Developer Activity** | Line Chart (`Year-Month` vs `Commit Count`), Matrix Heatmap (`Weekday` rows vs `Hour` columns, conditional background color by commits) |
| **Page 4** | **Repository Analytics** | Scatter Plot (`complexity_score` on X, `stargazers_count` on Y, size by `size_kb`, color by `primary_language`), Table of Repositories with Status formatting |
| **Page 5** | **Career Intelligence** | Horizontal Bar Chart (`role_name` vs `fit_percentage`), Multi-row Card showing `Strong Skills` vs `Missing Skills` |
| **Page 6** | **Peer Benchmarking** | Clustered Column Chart (`dimension` vs `percentile_rank`), Target Reference Line at 50th and 80th percentiles |

## 4. Quick Refresh Instructions
1. Open Power BI Desktop.
2. Click **Get Data** -> **Folder** (or **Text/CSV**) -> Point to `data/processed/powerbi/`.
3. Select **Load**.
4. Confirm relationships in the Model view.
5. In Power BI Service, configure Scheduled Refresh to read updated exports generated by the Python platform.
